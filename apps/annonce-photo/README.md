# Annonce à partir d'une photo

Appli 100 % navigateur : le client envoie 1 à 4 photos, choisit le type (immobilier, produit, restaurant, description), ajoute ses infos (prix, surface, contact…) et l'IA (Mistral, modèle vision) rédige l'annonce, prête à copier.

Usage : ouvrir `index.html`, ajouter la clé API Mistral dans « Réglages » (une seule fois, gardée dans le navigateur), puis envoyer des photos.

Attention : ne jamais écrire la clé API dans le fichier ni le publier avec une clé. Pour mettre l'outil en ligne pour des clients, il faudra un petit proxy qui garde la clé côté serveur.
