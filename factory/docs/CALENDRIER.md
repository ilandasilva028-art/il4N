## Comment ça marche
- L'ordre est dans `themes/visions.json` ; la routine prend la première vision non utilisée. Pour changer un jour, déplace l'entrée.
- `/scripts` affiche la file ; `/scripts <mot-clé>` en cherche une.
- Les idées marquées « à passer en 4 personnages » sont d'anciennes idées à un héros : la routine les réécrit dans le format gagnant (4 personnages, compteur, boucle, montage Remotion).
- Import agenda : `livraisons/calendrier-videos.ics` (un rappel par jour à 13 h 47, alerte 15 minutes avant).
- Les notes d'idées sont des **estimations** ; les statistiques TikTok réelles remplaceront cet ordre dès qu'elles existent.
