# Prospection

Usage : node fiches_appel.mjs contacts.csv [fiches.md]

Le CSV (séparateur ;) doit avoir les colonnes : nom;ville;telephone;site;note.
Le script garde les entreprises sans site et avec un numéro, puis écrit une fiche par entreprise avec le script d'appel.

Les numéros viennent de toi (export d'un annuaire que tu peux utiliser). Le fichier exemple_contacts.csv ne contient que de fausses données.
